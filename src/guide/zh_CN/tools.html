工具

ZIP 压缩包

Saladin 利用 Windows 资源管理器的标准功能处理 ZIP 压缩包。你可以像普通目录一样，通过双击或按 Enter 打开 ZIP 压缩包。你可以使用标准复制操作或拖放从 ZIP 压缩包中提取文件，或向现有压缩包添加文件。也可以在 ZIP 压缩包中创建文件夹，以及重命名和删除文件及文件夹。要向 ZIP 压缩包添加文件，请选择要打包的文件，选择 打包 命令（Ctrl+P），然后在目标目录中输入压缩包的名称。要处理其他类型的压缩包，请安装与 Windows Shell 集成的外部工具，例如 7-Zip。

FTP 连接

Saladin 还通过 Windows 资源管理器功能对 FTP 协议提供基本支持。要连接到 FTP 服务器，请选择 打开 > 连接到 FTP 命令（Ctrl+F），然后输入主机名或 IP 地址，并可选地修改端口号和初始路径。如果服务器需要身份验证，你还可以输入用户名和密码。也可以直接在位置栏中输入站点的 URL。FTP 连接支持复制、移动、重命名和删除等标准文件操作。

搜索

要在当前目录及其子目录中搜索文件，请选择 搜索（Ctrl+S）。使用通配符输入匹配模式，例如 *.txt。也可以输入多个模式，用分号分隔，例如 *.txt;*.ini。你还可以搜索包含指定文本的文件。启用 文本 选项并输入要搜索的文本。如果要执行区分大小写的搜索，请启用 区分大小写。搜索文本时，二进制文件将被自动排除在外。

搜索结果列表与主窗口中的列表类似，只是显示相对于当前目录的路径。列表还显示文件大小（字节）、文件最后修改的日期和时间以及文件属性。单击列标题可以按任意列排序。你也可以在项目上单击鼠标右键显示该项目的上下文菜单，双击则可以在默认应用程序中打开它。

使用 查看 命令（F3）可以在查看器中打开搜索结果中的当前文件。 查看全部 命令（Shift+F3）可以在内置查看器中快速查看所有搜索结果。最初会打开第一个匹配的文件，你可以在查看器中使用 上一个命令（P 或 Alt+LEFT）和 下一个命令（N 或 Alt+RIGHT）在匹配的文件之间切换。

使用 编辑 命令（F4）在文本编辑器中打开当前文件进行编辑。 转到文件 命令（Ctrl+G）将关闭搜索结果并在活动面板中高亮显示所选文件。 复制文件名 命令（Ctrl+Shift+C）可以将所有文件的相对路径复制到剪贴板。

浏览

可以使用 浏览（Ctrl+Shift+E）在 Windows 资源管理器中打开当前目录。

比较

你可以使用外部工具比较两个文件，例如 WinMerge 或 TortoiseSVN 中的 TortoiseMerge 实用程序。要配置该工具，请打开 Saladin 设置 并选择该工具可执行文件的路径。你可以在活动面板中选择两个文件，或在活动面板和目标面板中各选择一个文件，然后选择 比较 命令（Ctrl+M）运行比较工具。

使用 比较 > 比较目录 命令（Ctrl+Shift+M）比较当前目录和目标目录中的项目。该命令会选择当前目录中目标目录里不存在的所有文件和文件夹，以及比目标目录中更新的文件。这对于同步两个目录的内容非常有用。

书签

书签可用于记住常用的本地目录和 FTP 站点。单击 书签 图标并选择 添加书签（Ctrl+Shift+D），将当前位置以指定名称保存为书签。将 FTP 站点添加为书签时，你可以选择保存密码。

要打开书签，请单击 书签 图标或按 Ctrl+D，然后从列表中选择书签。激活 FTP 书签时，将打开 打开 FTP 站点 窗口，你可以输入密码或修改 FTP 站点的详细信息，而无需修改原书签。可以从 书签 菜单中选择 编辑书签 命令来删除和重命名现有书签。书签由两个面板共享，并在关闭 Saladin 时自动保存。

历史记录

每个面板都会记住最近访问过的目录。你可以分别使用 Alt+Right 和 Alt+Left 键转到上一个或下一个位置，如果你的鼠标支持，也可以使用额外的鼠标按键。你还可以单击 历史记录 图标或按 Ctrl+G，从列表中选择一个位置。
