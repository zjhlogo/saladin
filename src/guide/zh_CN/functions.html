基本功能

查看

查看命令（F3）使用内置或外部查看器打开当前文件（光标所在文件）。默认使用内置查看器。你也可以在 Saladin 设置 中选择其他外部查看器程序。

查看所选文件命令（Shift+F3）可以快速查看当前所有选中的文件。该操作仅在启用内置查看器时可用。最初会打开第一个选中的文件，你可以在查看器中使用 上一个命令（P 或 Alt+LEFT）和 下一个命令（N 或 Alt+RIGHT）在所选文件之间切换。

编辑

编辑命令（F4）在文本编辑器中打开当前文件进行编辑。默认使用系统自带的记事本程序，但你也可以安装更强大的编辑器，例如 Notepad++，并在 Saladin 设置 中选择它。你可以使用 编辑 > 新建文件 命令（Shift+F4）在当前目录中创建一个指定名称的空文件并在编辑器中打开它。

复制与移动

选中的文件和目录可以使用 复制（F5）进行复制，使用 移动（F6）进行移动。使用 复制 > 在源目录中创建副本（Shift+F5）在源目录中克隆所选项目。使用 移动 > 在源目录中重命名（Shift+F6）一次重命名多个项目。当源目录和目标目录相同时，操作将变为克隆或多重命名。

复制或移动单个项目时，可以直接在确认对话框中修改其名称。复制或移动多个项目时，可以通过单击 重命名 按钮打开批量重命名面板（在克隆或重命名时该面板会自动打开）。在某些情况下，如果 Windows 不支持，则不允许重命名。

在批量重命名面板中，可以在 名称 和 扩展名 字段中输入特殊的掩码，以生成所选项目的新名称。还可以使用 查找 和 替换 选项替换名称的任意部分。如果启用 正则表达式 选项，查找字符串可以包含正则表达式。替换在根据掩码生成名称之后进行。最后，可以使用 大小写 选项将结果名称中的字符转换为大写或小写。批量重命名面板底部的列表显示每个项目的原名称和新名称。

对于耗时较长的操作，传输文件期间会显示标准的进度对话框。当操作试图覆盖已存在的文件时会显示警告消息。选中 覆盖时不提示 选项后，文件将被直接替换而不显示额外警告。

新建文件夹

使用 新建文件夹（F7）在当前目录中创建一个指定名称的新子目录。

删除

使用 删除 命令或 F8、Delete 键删除所选项目。如果相应驱动器启用了回收站，文件和目录将被移入回收站。 删除 > 永久删除 命令或 Shift+F8、Shift+Delete 键将在不使用回收站的情况下删除这些项目。两种情况下都会显示额外的警告以确认操作。

打开控制台

最后一个基本功能是 打开控制台（F9），它会在当前目录中打开命令提示符。默认使用标准的 cmd.exe 程序，但你也可以选择其他控制台。Saladin 不包含内置的命令行解释器。
